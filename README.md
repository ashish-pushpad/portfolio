# Setup Guide

---

## Requirements

* Node.js **18+**
* npm (comes with Node.js)

---

## Installation

```bash
git clone <repository-url>
cd <project-directory>
npm install
```

---

## Environment Variables

Create a `.env` file in the project root:

```env
VITE_API_URL=
```

> No backend or API is required to run this project.

---

## Development

Start the local development server:

```bash
npm run dev
```

---

## Production Build

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Notes

* Built with **Vite**
* Always run `npm install` after cloning
* Update content inside `src/data/`
* Store images, GIFs, and assets in `src/assets/`
